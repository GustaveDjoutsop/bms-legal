2. Um welchen Dienst geht es?

AfroMarket ist ein Bestellservice, den Sie über WhatsApp nutzen. Sie schreiben mit einem Chatbot, wählen Produkte aus, geben eine Lieferadresse an und schließen die Zahlung über einen externen Zahlungsanbieter ab. Diese Erklärung beschreibt, welche Daten dabei verarbeitet werden.

3. Welche Daten wir verarbeiten

DatenkategorieBeispieleQuelle
Kontaktdaten WhatsApp-Telefonnummer, ggf. angegebener Name Direkt von Ihnen über WhatsApp
Bestelldaten Ausgewählte Produkte, Menge, Bestellhistorie Direkt von Ihnen über WhatsApp
Lieferdaten Lieferadresse, Postleitzahl, Land Direkt von Ihnen über WhatsApp
Zahlungsdaten Zahlungsstatus, Transaktions-ID (keine vollständigen Kartendaten) Stripe bzw. PayPal, an uns zurückgemeldet

Wir erhalten keine vollständigen Zahlungskartendaten – diese werden ausschließlich von Stripe bzw. PayPal verarbeitet.
